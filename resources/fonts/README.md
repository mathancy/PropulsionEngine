# Font Awesome Setup

Propulsion MK I uses Font Awesome 7 Free icons for the UI.

## Installation

1. Download Font Awesome 7 Free from: https://fontawesome.com/download
2. Extract the archive
3. Copy `Font Awesome 7 Free-Solid-900.otf` from the `otfs` folder to this directory
4. The file should be at: `resources/fonts/Font Awesome 7 Free-Solid-900.otf`

## Note

The engine will work without Font Awesome, but icons will not display. Instead, text fallbacks will be shown.
