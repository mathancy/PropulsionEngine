# Propulsion MK I Resources

This folder contains engine resources and assets.

## Structure

- **icons/** - Application icons and favicons
  - Place your favicon and window icon files here
  
- **fonts/** - Custom fonts (future)
- **shaders/** - Additional shader files (future)
- **textures/** - Engine default textures (future)

## Adding a Favicon

To add a custom favicon/icon for the engine:

1. Place your `.ico` file in the `icons/` folder
2. Update the window creation code to load the icon
3. Rebuild the engine

The icon will be displayed in the window title bar and taskbar.
